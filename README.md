# DIGITRON

### QUANTITATIVE DIGIT INTELLIGENCE

**Study every tick. Test every sequence.**

DIGITRON is an open-source research and trading platform for Deriv synthetic markets.

## Vision

Build an intelligent platform that collects market ticks, analyses last-digit behaviour, researches trading strategies, tests statistical performance and supports controlled automated trading.

## Core Features

- Live Deriv market tick collection
- Last-digit analysis
- Odd/Even and Over/Under research
- Streak continuation and reversal strategies
- Frequency and transition analysis
- Automated strategy generation
- Historical backtesting
- Performance ranking and analytics
- Demo trading
- Optional configurable Martingale
- Risk management and trading limits
- Web-based dashboard

## Technology

- Python and FastAPI
- React and Vite
- Deriv API
- PostgreSQL

## Development Status

🚧 Under active development.

The initial focus is market intelligence and strategy research. Automated execution will follow after testing and risk controls.

DIGITRON is a research and trading software project. No strategy guarantees profits. Trading involves financial risk.
